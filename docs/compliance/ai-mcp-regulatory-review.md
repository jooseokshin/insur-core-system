# 외부 AI(MCP) 연동 규제 검토

- 작성일: 2026-11-08
- 대상: 기간계 조회·시뮬레이션 기능을 MCP 서버로 외부 생성형 AI(예: Claude)에 여는 계획 (`docs` 의 MCP 구성안)
- 성격: **법률 의견이 아니다.** 공개 자료를 모아 검토할 항목과 현재 확인된 사실을 정리한 체크리스트다. 실제 도입 여부는 회사의 준법감시·법무·정보보호 부서가 판단한다.
- 출처 표기: **[공식]** 금융위원회 등 정부 발표, **[보도]** 언론·법무법인·민간 자료. 보도는 해석이 섞여 있으므로 원문으로 다시 확인해야 한다.

## 결론 요약

| 항목 | 현재 상태 (2026-11 기준) | 이 계획에 대한 의미 |
|---|---|---|
| 망분리: 생성형 AI | **예외로 제도화되지 않음.** 혁신금융서비스(샌드박스) 지정으로만 개별 허용, 전면 해제 TF 발족 예정 [보도] | 업무망의 기간계를 외부 AI 에 바로 연결할 수 없다. 혁신금융서비스 지정, 또는 내부망 설치형 모델을 써야 한다 |
| 망분리: SaaS | 일반 사무·관리 업무용 SaaS 는 2026-04-20 부터 예외. 고유식별정보·개인신용정보 처리 시 제외 [보도] | 생성형 AI 에 그대로 적용되지 않는다. 다만 앞으로 AI 도 비슷한 조건(정보 종류 제한, 보안 평가)이 붙을 가능성이 크다 |
| 금융분야 AI 가이드라인 | 2021-07 제정 [공식], 통합 개정안 시행 예정·시행 보도 있음. "AI 는 보조수단, 최종 판단은 임직원", 긴급 정지 기능 요구 [보도] | 설계 원칙(읽기·시뮬레이션만, 사람이 결정)과 맞는다. **긴급 정지 장치를 설계에 넣어야 한다** |
| AI 기본법 | 2026-01-22 시행, 최소 1년 계도기간 [보도]. 보험 인수·보험금 심사의 고영향 해당 여부는 불명확 [보도] | 요율 영향 분석(내부 의사결정 보조)은 고객 권리에 직접 영향이 적어 해당 가능성이 낮다고 **추정**. 보상 심사에 AI 를 쓰면 다시 검토해야 한다 |
| 보험요율 정보 | 요율 산출은 보험업법상 원칙(충분성·비과도성·공정성)과 감독 대상 [보도: 보험연구원 자료]. 요율 정보의 영업비밀 범위는 **확인 못 함** | 집계값이라 개인정보는 없어도 **요율안은 핵심 영업정보**다. 외부 AI 로 보내는 것 자체가 정보보호 검토 대상 |
| 개인·신용정보 국외 이전 | **확인 못 함** (검색으로 근거를 찾지 못함) | 계획은 개인정보를 보내지 않도록 설계했지만, 확장(보상 보조 등) 시 반드시 확인해야 한다 |

**판단**: 지금 조건에서 실제 보험사가 이 계획을 그대로 운영하는 것은 어렵다. 가능한 경로는 다음 둘이다.

1. 혁신금융서비스 지정을 받아 외부 AI 를 쓴다 (보안대책이 조건으로 붙는다).
2. 금융당국이 지원하겠다고 밝힌 방식처럼, **내부망에 설치한 모델**에 MCP 서버를 연결한다. MCP 는 모델 공급자와 무관한 규약이라 이 경로에서도 같은 구조를 쓸 수 있다.

## 설계에 반영할 요구사항

규제 검토에서 나온, 구현할 때 지켜야 할 항목이다.

- [ ] **읽기·시뮬레이션만** 연다. 변경 API(접수, 수납, 승인, 지급, 요율 개정)는 MCP 도구로 만들지 않는다 (보조수단성 원칙).
- [ ] **긴급 정지**: 설정 하나로 MCP 서버의 모든 도구를 즉시 막을 수 있어야 한다.
- [ ] **사용자 본인 권한**: 공용 계정 없이 사용자 토큰으로만 호출한다 (OAuth 로그인 방식).
- [ ] **전송 정보 최소화**: 개인정보·개인신용정보·고유식별정보를 응답에 넣지 않는다. 요율·손해율처럼 영업정보에 해당하는 값은 어떤 항목을 보내는지 목록으로 관리한다.
- [ ] **감사 기록**: MCP 를 거친 호출을 구분해 남긴다 (누가, 언제, 어떤 도구로, 무엇을 조회했는지).
- [ ] **호출 제한**: AI 가 반복 호출해도 기간계에 부담을 주지 않도록 사용자·도구별로 제한한다.
- [ ] **모델 교체 가능성**: 외부 모델과 내부망 설치형 모델 어느 쪽에도 붙을 수 있게 MCP 서버는 모델 공급자에 의존하지 않는다.

## 아직 확인할 것

- [ ] 생성형 AI 망분리 예외의 최종 제도화 여부와 조건 (금융위원회 보도자료, 전면 해제 TF 결과)
- [ ] 통합 금융분야 AI 가이드라인 원문과 시행일
- [ ] 과기정통부 「고영향 인공지능 판단 가이드라인」 원문에서 보험 업무의 취급
- [ ] 보험업법(제129조 등) 원문과, 요율 산출 자료의 영업비밀·외부 제공 제한 범위
- [ ] 개인정보 보호법·신용정보법상 국외 이전 요건 (외부 AI 의 데이터 처리 위치가 국외인 경우)
- [ ] 사용할 AI 서비스의 데이터 보관·학습 사용 조건 (계약 조건)
